A simple responsive QR code card built with only HTML and CSS using BEM class naming.

## What I learned

### 1. How to structure a small project

I learned how to organize a project into separate files:

- `index.html` for structure
- `styles.css` for styling
- `images/` for assets like the QR code image

This keeps the project clean and easy to maintain.

### 2. How to use BEM naming

I used the BEM methodology to make class names clear and scalable.

### 3. How to center content on the page

I used CSS Grid with:

```css
display: grid;
place-items: center;

### 4. How to style a card component

I learned how to build a card with:

    a white background
    rounded corners
    padding
    shadow
    centered text

These are common UI design techniques.
```
